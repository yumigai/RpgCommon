■雲上シェーダー Unity パッケージ／Heaven Shader Unity Package
床面を変形して雲上を再現するシェーダーとそれをアタッチした Plane プレファブがセットになった Unity パッケージです。
C# スクリプトを使用せずに実装されているので、VRChat のワールドにも組み込み可能です。

■セット内容
・HeavenShader.unitypackage
→ 雲上シェーダーとそれをアタッチした Plane プレファブなどをインポートできる Unity パッケージです。

・Readme.txt
→本テキストです。

■ご利用の前に
本パッケージのご利用には、ゲームエンジンの Unity が必要です。
また、VRChat ワールドへと組み込む場合には、別途 VRChat 公式のアバター／ワールド作成用 Unity パッケージが必要です。
Unity の基本的な使い方や、Unity を利用した VRChat のワールド作成方法については、本ドキュメントでは説明しません。
それぞれ公式のドキュメントをご参照ください。

■ご利用方法
Unity から HeavenShader.unitypackage をインポートしてご利用ください。

■Shader プロパティ―（設定項目）について
・Albedo (RGB)
→ 基本のテクスチャーです。
・Cloud Resolution
→ 雲の細やかさです。
・Cloud Height
→ 雲の高さです。
・X Speed
→ 雲が X 軸方向に流れるスピードです。
・Y Speed
→ 雲が Y 軸方向に流れるスピードです。
